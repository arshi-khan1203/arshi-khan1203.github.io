Overview

This artifact is a six-slide visual presentation created for AIML-501 (Model Development) at Indiana Wesleyan University. It compares four pre-trained models across four domains: BERT (NLP), GPT-4 (Generative AI), MobileNet (Computer Vision), and XGBoost (Tabular Data), using a color-coded decision matrix to make trade-offs immediately readable for both technical and non-technical audiences.

The core argument is that no single model is universally optimal. Effective model selection requires deliberate analysis of size, accuracy, speed, explainability, data requirements, and deployment cost in the context of the specific use case.

Explanatory Document

This artifact presents a visual decision matrix comparing four pre-trained models across four domains: BERT (NLP), GPT-4 (Generative AI), MobileNet (Computer Vision), and XGBoost (Tabular Data). The presentation examines each model across six criteria including model size, accuracy, inference speed, explainability, data requirements, and deployment cost. The core argument is that no single model is universally optimal. Model selection requires deliberate trade-off analysis based on the deployment context, available resources, and task requirements. BERT offers strong NLP accuracy at manageable compute cost but lacks explainability. GPT-4 delivers unmatched reasoning capability but at significant size and cost. MobileNet excels in speed and efficiency for edge vision tasks while accepting moderate accuracy trade-offs. XGBoost stands out as the most interpretable and resource-efficient option for structured data, making it particularly valuable in regulated industries where explainability is a requirement rather than a preference.

The color-coded decision matrix was chosen as the primary visual format because it allows viewers to compare models across multiple criteria simultaneously without requiring deep technical knowledge. Green indicates favorable characteristics such as small size, high speed, or strong explainability. Amber signals moderate trade-offs, and red highlights less favorable attributes for resource-constrained or transparency-focused deployments. This visual encoding makes the trade-offs immediately readable at a glance. The card-based model profile slide was designed to present each model's specifications in a consistent, scannable format, ensuring the audience can quickly locate the data points most relevant to their use case. Overall, the presentation reflects the principle that effective AI decision-making requires understanding not just what a model can do, but what it costs and whether its decisions can be explained.
